# Flipkart Order Intelligence & Support Assistant

This repository implements the three connected Parts from the supplied assignment brief.

## Repository layout

- `generate_orders.py`, `orders_dataset.csv` — Part 1 deterministic data.
- `part1/` — training/evaluation code and evidence.
- `models/return_risk_model.pkl` — final tuned Random Forest artifact consumed by Part 3.
- `models/t_rf.txt` — F1-maximising threshold from the Random Forest's own test-set `predict_proba`.
- `part2/` — Fashion-MNIST transfer-learning training/evaluation.
- `models/product_classifier.pt` — saved classifier after Part 2 training.
- `data/sample_images/` — five real Fashion-MNIST test images exported by Part 2.
- `part3/` — policy KB, vector index builder, tools, agent, retrieval evaluation and transcripts.

## 1. Install

```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS/Linux:
source .venv/bin/activate
pip install -r requirements.txt
```

## 2. Part 1 — Return Risk

Generate the exact seeded dataset:

```bash
python generate_orders.py
```

Train the DummyClassifier, Logistic Regression threshold sweep, and Random Forest GridSearchCV:

```bash
python part1/train.py
```

Run the full evaluation/evidence report:

```bash
python part1/evaluate.py
```

Expected artifacts:

```text
models/return_risk_model.pkl
models/t_rf.txt
part1/evaluation_results.txt
part1/threshold_sweep.csv
part1/permutation_importance.csv
```

The saved model is the tuned Random Forest, not the Logistic Regression. `t_rf` is computed from that Random Forest's own held-out test `predict_proba`.

## 3. Part 2 — Product Image Classifier

This Part uses Fashion-MNIST and a pretrained ResNet-18 with a frozen backbone and trainable 10-class head.

```bash
python part2/train.py
python part2/evaluate.py
```

The first run needs network access to download Fashion-MNIST and the pretrained ResNet weights. No API key is required.

Expected artifacts:

```text
models/product_classifier.pt
data/sample_images/*.png
part2/confusion_matrix.txt
```

The five PNGs must be real test-split images generated by the training script, not screenshots or fabricated files.

## 4. Part 3 — Policy RAG + Agent

Build the local vector index:

```bash
python part3/build_index.py
```

Evaluate document-level Precision@3 and Recall@3:

```bash
python part3/evaluate_retrieval.py
```

Run the deterministic agent:

```bash
python part3/agent.py
```

The two real model tools are in `part3/tools.py`:

- `check_return_risk(order_features)`
- `classify_product_image(image_path)`

The agent uses explicit state passed between turns, a conditional intent route, injection filtering, and a groundedness threshold for policy answers.

## 5. Required transcripts

The assignment requires 8+ test conversations. The `part3/transcripts/` directory contains the eight required scenarios as run-record templates. After the local models/index are built, replace the placeholder lines with the actual outputs from your run. Do not invent metrics or model outputs.

Required scenarios include:

1. policy — apparel return window
2. policy — COD refund
3. return-risk tool call
4. image-classifier tool call
5. multi-turn state carried across turns
6. fresh conversation with reset state
7. prompt-injection attempt blocked
8. ungrounded policy question refused with similarity score and threshold
